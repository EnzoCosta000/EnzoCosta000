# 💼 Projeto em destaque

## 🍻 Bar do Cabeça — Sistema de Gestão

Um dos meus principais projetos acadêmicos é o **TCC desenvolvido para o Bar do Cabeça**, um bar e mercearia.

O projeto nasceu a partir da análise de problemas reais encontrados na gestão do estabelecimento, como:

* 📋 Controle manual de comandas
* 📦 Dificuldade no controle de estoque
* 💰 Controle financeiro pouco preciso
* 📊 Falta de indicadores para tomada de decisão
* 📱 Ausência de um cardápio digital integrado

### 💡 A solução

A proposta é desenvolver um **sistema web integrado** para centralizar esses processos e tornar a gestão mais organizada, eficiente e confiável.

### 🧩 Tecnologias utilizadas

**HTML + CSS + JavaScript + Node.js + EJS + MariaDB + Sequelize**

Além da programação, o projeto envolve:

* Levantamento de requisitos
* Modelagem de banco de dados
* Desenvolvimento da interface
* Estruturação do back-end
* Integração com banco de dados
* Documentação do sistema
* Organização e versionamento do projeto

> Mais do que um trabalho acadêmico, o objetivo é entender como a tecnologia pode resolver problemas que realmente existem fora da sala de aula.
