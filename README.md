# 💼 Projeto em destaque

## 🍻 Bar do Cabeça — Sistema de Gestão

Um dos meus principais projetos acadêmicos é o **TCC desenvolvido para o Bar do Cabeça**, um bar e mercearia.

A ideia surgiu a partir de problemas reais encontrados na gestão do estabelecimento, como:

* 📋 Controle manual de comandas
* 📦 Dificuldade no controle de estoque
* 💰 Controle financeiro pouco preciso
* 📊 Falta de indicadores para tomada de decisão
* 📱 Ausência de um cardápio digital integrado

### 💡 A solução

O projeto busca centralizar esses processos em um sistema web, permitindo uma gestão mais organizada e eficiente.

No desenvolvimento, estou trabalhando com:

**HTML + CSS + JavaScript + Node.js + EJS + MariaDB + Sequelize**

Além da programação, o projeto envolve **levantamento de requisitos, modelagem de banco de dados, documentação, desenvolvimento da interface e organização do sistema**.

> Mais do que um trabalho acadêmico, o objetivo é entender como a tecnologia pode resolver problemas que realmente existem fora da sala de aula.
